These eight tables hold the vocabularies the whole system shares. Every status column in the schema is a foreign key into one of them — so a typo like COMPLETEDD cannot be stored at all.

Order status vocabulary

PENDING_PAYMENT CONFIRMED PREPARING READY_FOR_PICKUP OUT_FOR_DELIVERY COMPLETED CANCELLED
Seven values, one authority. Order.status is the only column that decides where an order is in its life.
Why lookup tables instead of ENUM. An ENUM change needs an ALTER TABLE — a schema migration — every time the market adds a status. A lookup row is just an INSERT, and it can carry a human-readable label the admin can edit without touching code.
