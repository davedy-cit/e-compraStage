About these mockups

What they are. Static HTML pages that show layout, content and interaction intent. They are the design reference the Django templates and Vue components will be built against — not the application itself.

What they are not. Nothing here is wired to a database. Buttons do not submit, forms do not post, and every figure is sample data that matches the seed script so the screens tell one coherent story.

No JavaScript, deliberately. Every page is HTML plus a single shared stylesheet. That keeps the wireframes readable as documents and makes them render identically wherever they are opened — including in a screenshot tool with scripting disabled.

One stylesheet. All sixteen screens link assets/mockup.css, so a change to a colour token or component updates the whole set at once.
