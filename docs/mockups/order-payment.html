Payment status states

These four values are a lookup table (orders_paymentstatus), not free text — so a typo can never create a fifth state.

  • PENDING
    Initiated, not yet settled. The order waits here.
  • VERIFIED — current
    Settlement confirmed by the provider. This is the only state that releases an order for preparation.
  • FAILED
    Settlement failed or was declined. The customer may retry.
  • REFUNDED
    Money returned to the customer, e.g. after a cancellation.
